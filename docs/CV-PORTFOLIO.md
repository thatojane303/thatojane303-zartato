# ZarTATO portfolio notes — current status

**Status checked 2026-11-09:** pre-launch, not deployed. This file replaces an earlier portfolio draft that overstated BSC deployment, Chainlink integration, reserve backing, and production readiness.

## Accurate project description

ZarTATO is an educational fixed-supply ERC-20 experiment intended for Base. The repository contains the Solidity token contract, Hardhat tests, and manual testnet deployment tooling. The full supply is minted to the deployer at deployment; public mint and burn calls revert.

## Current limits

- No Base deployment or live public product is recorded.
- No real potato-market data source, onchain oracle, or Builder Code integration is implemented.
- Thandi is a local example-data mock only.
- No reserve backing, liquidity pool, lock, vesting, or audit is present.
- Do not describe this project as production-ready or deployed.

## Skills shown by the repository

Solidity and OpenZeppelin ERC-20 patterns; Hardhat unit testing; Node.js tooling; GitHub Actions CI; documentation of deployment and token-supply constraints.
