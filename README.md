# ZarTATO (ZRT) — Educational Token on Base

> **Educational & Cultural Experiment on Base L2 — Inspired by BRETT**

ZarTATO is a community-driven educational ERC20 token on Base blockchain. Fixed supply, trade-only model, no farming, no agricultural backing, no yield promises.

**DISCLAIMER: This is an educational meme/cultural experiment. No intrinsic value. Not financial advice.**

## Model: BRETT Trade-Only
- Fixed Supply: 1,000,000,000 ZRT (1 Billion) — no mint, no inflation
- Network: Base Mainnet (8453) + Base Sepolia Testnet (84532)
- DEX: Aerodrome Finance (primary liquidity)
- No farm, no co-op, no potato price peg, no reserve backing
- 100% price discovery via DEX trading

## Tokenomics (Proposed)
- 40% Aerodrome Liquidity Pool
- 15% Oracle & Infrastructure (Thandi price feed - informational only)
- 15% Community & Education (Musa Bot - /price commands)
- 15% Team (12-month lock)
- 15% Treasury / Grants

## Tech Stack
- Solidity 0.8.20 + OpenZeppelin ERC20
- Hardhat deployment
- BaseScan verified
- Thandi.js: informational price feed only (no on-chain backing)
- Musa Bot: educational /price command
